## 변경 기록

- 2026-11-14 — 요구사항을 `architecture.md`에 정리하고 `implementation-plan.md`에 구현 순서와 완료 기준을 기록했다. 프로젝트 루트의 `AGENTS.md`에 작업 전 문서 조회와 작업 후 갱신 규칙을 추가했다.
- 2026-11-14 — 초기 문서 네 개의 UTF-8 인코딩과 상대 링크를 확인했다.
- 2026-11-14 — Next.js 14.2.35와 Tailwind CSS 3.4로 UI를 구현했다. `npm.cmd run build`가 성공했고 `/`와 `/board` 모두 HTTP 200을 반환했다. 같은 브라우저의 두 탭에서 손그림으로 등록한 카드와 열린 상세 창의 댓글, 보드 댓글 수가 새로고침 없이 갱신되는 것을 확인했다. 실제 사진 파일 첨부와 모바일 터치 조작은 미검증이다.

- 2026-11-14 — Supabase에서 두 독립 클라이언트로 이미지 등록·공개 조회, 방명록과 댓글의 실시간 INSERT 수신, 댓글 수 조회, 동일 요청의 중복 방지, 공개 역할 직접 쓰기 차단을 확인했다. 프로덕션 빌드도 통과했다.

- 2026-11-15 — 인증·인가 도입안을 작성했다. 저장소의 Edge Function, DB 마이그레이션, 브라우저의 인증 헤더와 실시간 구독 코드를 대조하고 Supabase 공식 문서에서 사용자 토큰 검증과 DB·Storage 백업 범위를 확인했다. 문서 변경은 `git diff --check`를 통과했다. 현재 구현과 배포는 기존 방식이다. 이메일 발송, 인증·인가 동작, SQL 마이그레이션 및 운영 전환은 미검증이다.
- 2026-11-15 — 인라인 로그인·가입, 이메일 확인·비밀번호 재설정, 작성자 확인, 서버 전용 등록 RPC와 공개 역할의 Storage 쓰기 제한을 구현했다. `npm.cmd run typecheck`, `npm.cmd run build`, `deno check`를 통과했다. 격리 PostgreSQL에서 기존 행과 공개 조회 보존, 직접 쓰기·RPC 호출 차단, 동일 요청 재시도, 계정 간 충돌, 이미지 교체와 계정 삭제를 확인했다. 모의 Auth·Storage·Data API를 연결한 Edge Function에서는 토큰·이메일 상태에 따른 응답과 등록 RPC의 작성자 전달을 확인했다. 실제 이메일, 브라우저 세션 흐름, 동시 DB 연결과 Realtime, 호스팅 Supabase 마이그레이션 및 배포는 미검증이다.
- 2026-11-15 — 가입 장애 문의를 확인했다. 연결된 Supabase 로그에서 가입 요청 성공과 뒤이은 로그인 자격 증명 거부를 확인했고, 최근 한 시간에 생성된 계정 한 건은 이메일 인증을 완료한 상태였다. 기본 이메일 링크와 Site URL 복귀를 처리하도록 콜백을 수정하고, 가입 확인 메일 재발송 및 오류 안내를 추가했다. 타입 검사, 링크 파싱 시나리오 검증, 임시 작업 폴더의 프로덕션 빌드를 통과했다. 수정 후 실제 메일 수신과 비밀번호 변경은 미검증이다.

- 2026-11-15 — GitHub 반영 전 `npm.cmd run typecheck`, Edge Function `deno check`, `git diff --check`를 다시 통과했다. 운영 Supabase 전환은 별도 단계다.
