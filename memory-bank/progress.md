## 변경 기록

- 2026-11-14 — 요구사항을 `architecture.md`에 정리하고 `implementation-plan.md`에 구현 순서와 완료 기준을 기록했다. 프로젝트 루트의 `AGENTS.md`에 작업 전 문서 조회와 작업 후 갱신 규칙을 추가했다.
- 2026-11-14 — 초기 문서 네 개의 UTF-8 인코딩과 상대 링크를 확인했다.
- 2026-11-14 — Next.js 14.2.35와 Tailwind CSS 3.4로 UI를 구현했다. `npm.cmd run build`가 성공했고 `/`와 `/board` 모두 HTTP 200을 반환했다. 같은 브라우저의 두 탭에서 손그림으로 등록한 카드와 열린 상세 창의 댓글, 보드 댓글 수가 새로고침 없이 갱신되는 것을 확인했다. 실제 사진 파일 첨부와 모바일 터치 조작은 미검증이다.

- 2026-11-14 — Supabase에서 두 독립 클라이언트로 이미지 등록·공개 조회, 방명록과 댓글의 실시간 INSERT 수신, 댓글 수 조회, 동일 요청의 중복 방지, 공개 역할 직접 쓰기 차단을 확인했다. 프로덕션 빌드도 통과했다.
